AI-Powered chrome extansion 
An all-in-one browser extension leveraging LLMs (OpenAI API) to enhance workflow through 5 core modules:
1. Code Annotator: Automatically generates meaningful comments and documentation for code snippets.

2. Professional Enhancer: Refines English text to a professional/academic level.

3. Creative Lyricist: Rephrases text with a rhythmic, "song-like" flow and creative tempo.
   
4. Smart Summarizer: Distills lengthy articles into a single, cohesive paragraph.
   
5. Quiz Architect: Generates multiple-choice (American) quizzes based on highlighted text for active learning.
